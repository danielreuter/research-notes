## Statement (`vllm_block.rs`): HOLDS
- **Block layout.** One block per VU, k_log 21: 25 + 25 SHA-256 slots (2^15 bits each, Flock's upstream `sha2`
  circuit), then the 48 units at positions 200–247.
  - per_role = ⌈(26 + 1536 + 9)/64⌉ = 25.
- **Constants in Δ.**
  - Slot 0 of each role gets the SHA-256 IV. Slot j ≥ 1 copies the previous slot's H_out; H_out includes the
    feed-forward, so the last slot holds the digest.
  - Every message byte outside [26, 26 + row_bytes) is a constant: the 18-byte tag plus u64be(1536), then the FIPS
    padding 0x80…u64be(8·1562). The constants come from `pos_leaf_message(zeros)`, and those bytes don't depend on the
    row.
  - So the leaf rule and the value length belong to the statement.
- **Operand map.** Row byte t goes to slot ⌊(26 + t)/64⌋, byte (26 + t) mod 64, bit 8·(3 − o%4) + i of the big-endian
  word. Units straddling message blocks copy bit by bit. `unit_inputs` uses the same map, and a Rust test covers it.
- **Accumulators and constants.** The accumulator chain is in-block, with c_in(0) = +0. All constants copy the pinned
  column.
- **Regions.**
  - Each role's digest: H_out bits of slots 24 and 49, 8 free bits.
  - The output word: unit 47's c_out, or y16 with an epilogue.
  - PT_LOCAL is 8, which covers the region free bits.
- **Dummy blocks.** They are position leaves of zero rows with a zero-input unit chain.
- **Statement digest.** It covers the parameters, the netlist sha, and Δ.

## Verifier (`flock-vllm-v1.rs` + `vllm_block::v1`): HOLDS
- **Commit.** `statement_publics` folds the prover's digests per role, VU v as leaf v: `node` on pairs, `lift` on an odd
  tail, no padding. It binds the tree root with `Domain::bind` (the step root: tag, program, ctx, geo, layout, u64be N,
  tree root) and compares against the held root. This happens before any coin, so a swapped, forged or bare-tree-root
  digest is refused there.
- **Domains.** The port domains come from the relation's shape and the verifier's own instance reference. `Domain::of`
  reproduces B-Ligero's port domains; the Rust test `port_domains_match_b_ligero` passes, and the instance header's
  domain digests are asserted equal.
- **The y root** is checked against the verifier's own output words.
- **Σ** covers the relation, sizes, the netlist sha, the statement digest, the instance reference, and the three domain
  digests and bound roots.
- **Params** are pinned to Fast100. Each rep carries 6 extra claims (3 regions × 2 points), with y = 0 and no
  cross-field link.
- **Session library:** the reviewed flock-live lib (with the route (a) Prime merge), unchanged for this statement.

## Lincheck fold (`VllmCircuit`): HOLDS
It has the same structure as pure_block's generalized fold: sub-block 2^15 (4 unit-size parts per slot) and units at
2^13, scaled per slot or unit by the eq tensor's high part, plus the Δ scatter. It is correct for a tensor-product eq.
