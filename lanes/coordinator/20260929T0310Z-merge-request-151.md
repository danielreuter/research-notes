- **Decision on the allowance:** not loosened. The first version widened the fixed allowance from 16 KiB to 32 KiB. The failure
  came from a nondeterministic measurement, so the test was made deterministic instead:
  - **Why it varied:** `tracemalloc` summed every block allocated in the process during the window. That total depended on:
    - first-use costs paid by whichever test ran first;
    - CPython's per-class instance sizing for the layout objects built inside the window;
    - numpy's own blocks after `np.cumsum`, whose count varies between identical runs (7–17 KB).
  - **The fix:**
    - the layout is built before the window, and an untraced warm-up commit pays the first-use costs;
    - a block counts only when a commit frame is on its stack, so other threads are excluded;
    - numpy's own Python-heap blocks are excluded, while array buffers always count;
    - the bound is the declared state by `sys.getsizeof` (5,629 B) plus 1 KiB for numpy's shape cache.
  - **Measured:** 5,709 B in every context tried: alone ×3, after `test_roundtrip.py`, after `tests/commit`, and under xdist
    `--dist loadfile`.
