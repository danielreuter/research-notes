## For other lanes

The contract is `backends/direct/ligero/leaf/base.py` (unchanged since 0d7d716; `check_scheme(s)` is the static check, `leaf/conformance_test.py` the dynamic one — run it on your pod with `VERITY_LEAF_CONFORMANCE=<your suffix>`):

~~~python
class LeafScheme(Protocol):
    name: str; assumption: str; digest_elems: int; carry_elems: int; schema: str; params_sha256: str; hash_name: str
    def native(self, rows: np.ndarray, *, word_bits: int, role: int) -> np.ndarray: ...        # (n, row_words) -> (n, digest_elems) BabyBear
    def leaf_bytes(self, digest_row) -> bytes: ...                                              # the SHA-256 tree leaf value (ValueError = malformed)
    def gadget(self, ctx, words, *, word_bits: int, role: int, row_words: int, carry_in, first=False, last=True) -> tuple[list, list]: ...
    def witness(self): ...                                                                      # WitnessHook | None (device rows)
    def chain_witness(self, words, *, word_bits, role, row_words, n_vus, steps, l): ...         # (carry_rows, digest_rows[, extras])
    def census(self) -> dict: ...
~~~

Relation string = `<rel>[+<suffix>]`; `suffix` omitted for poseidon2 (byte-compat with every v5 statement / Rust fixture on main), `+hash` is an alias.
