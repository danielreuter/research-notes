# Red-team: #1215 at `ba394c6b9c1e53729966a9f8e937c39e39fe795d`: GRANT

#1215 makes `verity_flock.class_statement._source_digest` (the code digest in `FLOCK_STAGE_CACHE`'s key) skip every
directory or `.py` file whose name holds a dot. It changes one function, and a test, on main `378453fb3`.

**What a cache key must not do** is hit on stale inputs: a file that staging runs, edited without the key moving.

- Python's import statement can't reach a module through a dotted directory or file name. So the only way to run such a
  file is a load by path. The four by-path loads in the hashed packages are these:
  - `class_statement.py:1311`, `--program-module`. The program it builds is in the key by `program_sha512`.
  - `verity_vllm/correspondence/capture_identities.py:661` and `verity_vllm/protocol_options/pouw_pearl_c_device.py:187`.
    Both are vLLM runtime loaders, not staging code.
  - `circuit_check/cache.py`'s `SourceFileLoader` hook, which wraps imports and adds no load of its own.
- No tracked `.py` file in the seven hashed package roots has a dotted name in its path. The only tracked one in those
  trees, `integrations/vllm/fixtures/B0-divergence-…/layers.0.self_attn.rotary_emb/…`, is outside `verity_vllm/`'s root
  and was never hashed. So today the change leaves out only untracked trees: `.lake`, `.venv`, `.pytest_cache`.
  `test_todays_digest_is_the_one_portion_walk` pins that, since it compares against the `rglob` walk less the dotted names.
- `Path.walk` doesn't follow symlinks, and `rglob` may. The test above passing on today's tree shows that no symlinked
  directory with Python in it sits under a root.

**Run:** in a worktree at the head, `test_class_statement_redteam_1178.py` passed, 5 of 5. With main's
`class_statement.py`, the new test fails (1 failed, 4 passed), so it catches what it claims to catch.

**Not blocking:** this holds only while staging loads nothing by path from a dotted directory under a hashed root. A port
directory named like `qwen2.5/` holding a `static_config.py` that staging read would fall out of the key. Nothing does
that today.
