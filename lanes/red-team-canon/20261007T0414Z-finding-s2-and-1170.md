## #1192: the canonical format under `--zk`

**What `verify` newly accepts.** `ProvedScope.check` ends in `scopeOk c || canonicalOk tags zk c`, where `canonicalOk`
is `zk && tags.hiddenOutputs && c.outNet == c.unitNet && formatOk c`. The only sessions newly accepted have all of these:
- `--zk`, hidden outputs, and a circuit outside `scopeOk` that passes `formatOk`;
- no shared-row public file and no public input ports (the earlier rules still apply);
- a subset draw.

Every other draw is refused:
- `canonicalLaw` refuses a stratified draw at setup, after `drawLaw`, whenever `canonicalAt` holds.
- `drawLaw` already refuses bernoulli and work draws.
- A session with no draw is refused last.

Each accepted session falls in the `else` branch of the hidden `--zk` conjunct, `SoundZHJC I _`. That is over
`Law.execOS … (.subset kd)` at J tables and is proved by `Canonical.zk_session_soundC_verifies`. `ViewZHJ` uses only
`hs.typed`, so zero knowledge covers these sessions too. I found no newly accepted form that this misses.

**Lean and Rust agree.** `proved_scope::check` accepts on `circuit_why = None`. Otherwise it refuses without `--zk`, and
under `--zk` it accepts on `canonical_why = None`, else refuses with `canonical_why` when any port is a bit row (else
with `circuit_why`). That is the Lean `circuitWhy` order, with the same strings. In more detail:
- Rust `bit_row` (`v2 || segs.is_some()`) is the Lean `Port.v2`.
- `out_rows` is `ports[n_in..]`, and the parser pins its length to `out_row_ports`.
- `leaf_cuts` and `leafCuts` both index by `(unit, port, leaf)`.
- The Rust twin assumes hidden outputs, which holds: the three untyped tags all have `hiddenOutputs := true`, and
  `statementRules` refuses typed statements.

**`zk_session_sound_canonical`** counts `(keyProg …).partition (…).wrong`, the same set every `FailClosed` conjunct
counts. The body says that and no more, and it names main's `wrongRegZ` as the stronger count it does not reach.

**The rest of the patch:**
- `parse_formatOk` is what the body says: V1's executable check gives `formatOk` (`formatOk_of_provedScope`) and the
  hidden-output facts that `ScopeZ.formatOk` and `ScopeZ.hidden` use.

  `test_lean_canonical_format.py`.
