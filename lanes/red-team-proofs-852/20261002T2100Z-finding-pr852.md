# Red team PR 852 (two-stage exfiltration): GRANTED

Scope: only the new TwoStageExfil.lean, one import line, and lean-audit.json additions (two new pins; the only '-' line is a list-separator change). The new code is a thin composition of the already-merged Refines.twoStage_influence (Influence.lean) with a generic counting lemma.

Game: twoStage = send R; coin w1; send I (Int (draw w1)); coin w2; session. The interior is picked after the coarse draw, and m is fixed before every coin (sigma : M -> Strategy). The delivered value is out D (X (reg2 sigma) ...), and in the Flock instance it is out D of R, the coarse registration. Definitions are not trivial: effEscape = avg_w1 prod_{u in B cap S1} sup_{v, parent v = u} (1 - incl v). IsHarmBoundOn is IsHarmBound with an arbitrary escape (Iff.rfl). LoweringSound and AnchorsSound2 are explicit hypotheses carried over from flock_two_stage_sound; nothing is hidden.

Blocking: none.
Non-blocking:
1. The additive delta must exceed effMiss(k+1), so a small k gives a weak bound (see the numbers below). Docstrings should say that delta is paid in full and is not a tail.
2. AnchorsSound2 at delta_in remains an open hypothesis in the Flock instance. The PR body says so; downstream claims must not quote the bound with delta_in = 0.
3. The scope is the oracle layer only, as the PR states (the executable acceptance is #828).

Numeric check: L1 Bernoulli(1/2) over coarse units, L2 uniform 1-of-4 fine units, the prover places one wrong fine unit per wrong coarse unit. Per-unit escape = 1/2 + 1/2 * 3/4 = 7/8, so effEscape(B) = (7/8)^|B|. With k=1, effMiss(2) = 49/64 ~ 0.766: the hypotheses are satisfiable with delta just above 0.766. Then H = 64 (singletons only), and the bound is 2^64 (1 + nc)/|M| + 0.766 + 2^-205 + delta_in. That is true but weak. For delta ~ 2^-40 you need |B| >= 40/log2(8/7) ~ 208, so k = 207 and H = 208*64 = 13312 bits, plus log2 sum_{j<=207} C(nc, j). That is the honest price of committing the interior late.
