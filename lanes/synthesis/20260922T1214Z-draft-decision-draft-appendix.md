   verify 0.245 s, 5.9 MB, "SP1 core (~100 bits)", authentication *included* (r20260921-220722-019b); relation-only
   diagnostic 0.868 s/VU (r20260922-050349-3373, 8.82e10). Caveat: B=1; there is no batch run, so "14,664 s per 4096"
   is an extrapolation and its soundness is not 2^-128.
2. **autoproof** (baseline, read-only review). Autoproof is a measured *negative* result for exact-FP transducer proving

   rates; the sub-1e4 numbers are unbuilt data-dependent designs. No run id.

   on q32/BabyBear^6 1.08e7 vs 1.07e7 (1.01x). Model, not a proof; closed as not worth a lane.
